# How I Created this E-Portfolio with GitHub

## Intro
- This E-Portfolio is a subpage of my GitHub website 
- I will display some of my different projects that I have completed over the course of my career
- In order to create this, I used only markdown commands through my GitHub online repository and GitHub desktop
- Below I will explain how I was able to create this subpage

## Creating the GitHub Pages Repository 
1. You first will want to create a GitHub Account by going to GitHub.com and creating one
2. After you have created your account, you then must create a Repository
3. Once this Repository is made you should then download GitHub Desktop and Login to your account
4. Once logged in you should clone this Repository (I named mine something different to differentiate)
5. After being cloned you should make sure this repository is held somewhere differently than the main

*Congrats you have made and cloned a GitHub Repository

## Setting a theme to our E-portfolio
1. Before we view our E-Portfolio we must choose a theme and place it in our cloned Repository
2. For this we have chosen the Minimal theme, in order to move it to your repository you must first Unzip the project
3. Once unzipped place it directly in your cloned repository
4. Once done, you should Copy and Paste the name of your repository on a new page and you should be met with a page that looks exactly like the minimal theme

*Congrats you have set a theme for your E-Portfolio*

## Changing the contents of your E-Portfolio
1. Now that our Portfolio has been created, go to GitHub desktop and open the repository in explorer
2. To change our logo, we must download our headshot and convert it to a png file and rename it to index.png
3. Once renamed go to the assets and then img folder and replace the logo with your headshot.
4. Once this is done go to the main file page where assets are then scroll down to index
5. Move this index folder and delete the markdown on the file and replace with information that you would find in your resume that you want to present
6. Adding different types of markdowns is a good way to split up your portfolio and adding elements

Here is a list of elements that can be used
- # Header 1
- ## Header 2
- ## Header 3
- 1. Numbered list
- Un-Ordered list
- **Bold**
- *Italicized*

7. Add these markdowns to headings, dates, lists, and any other information you would like highlighted as you see fit
8. Once you have made these changes you can move the index file back to its original folder
9. Go to GitHub Desktop and Commit these Changes to main, and then go to the top button and press push to origin
10. You should then be able to see updates made to your E-Portfolio

*Congrats you have added a headshot and resume to your E-Portfolio*

## Creating a Subpage
1. Once you have created this E-Portfolio go to your GitHub pages to your cloned repository
2. Go to the top right and press create new file
3. in the name box type in subpage_1/index.md
4. This will turn subpage into a folder which items can be added too
5. Press Commit changes and commit changes again

*Congrats you have made a subpage*
